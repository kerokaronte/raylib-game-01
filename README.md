# raylib-game-01
Pequeño prototipo de minijuego para probar la librería raylib.h en C++, como principante :p

El código es uno solo en un .cpp, al igual que el ejecutable. Los únicos controles son ENTER en el menú para iniciar el juego, WASD para mover el personaje (que es un cuadrado, nada especial lol), y R si se acaba la partida.

## Nota

Pueden haber comportamientos extraños o errores, es solo mi primera prueba con Raylib y las bases que tengo de C++.
